# Files

- [Fraud Check Integration (FSP-Go)](fraud-check.md) - The fraud check integration with FSP-Go provides domestic transaction fraud detection by calling an external service.
- [NAPAS Gateway Integration](napas-gateway.md) - Handles authentication and transaction querying for the NAPAS payment gateway, supporting OAuth2 token management and error code mapping.
- [Onecomm Gateway](onecomm-gateway.md) - HTTP client that talks to the Onecomm payment service using Hessian binary encoding, handles request signing via HMAC-SHA256, and provides the low-level API surface for card verification, authorization, and refunds.
